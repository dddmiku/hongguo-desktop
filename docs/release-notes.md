红果桌面 1.2.2：播放性能、返回播放和弹幕节奏优化。

- 支持显卡硬解的片源直接封装原视频，减少每集 FFmpeg 重编码的 CPU 与内存开销，保留原画质；不支持时自动兼容转码。
- 视频转换限制并发与解码线程，减少预加载和播放争抢资源；最小化、离开播放页时暂停播放与预取。
- 点击头像、设置、历史或收藏后可以通过“返回播放”继续原剧集，无需重新搜索进入；“结束播放”才关闭当前播放器。
- 修复稀疏弹幕达到数量上限后形成左右两批、中间空带的问题，改为均匀入场和轨道错开补位。
- 弹幕文字测宽缓存，暂停时停止持续重绘；大剧集选集列表减少重复渲染。
- 保留完整历史、跨端同步、收藏反馈、手机表情、真实全屏与无感切集。
