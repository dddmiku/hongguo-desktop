红果桌面 1.0.0 从源码构建，使用独立的 Electron、React 和 TypeScript 客户端。

这是新客户端的初代正式版本。旧版 1.9.9 用户通过旧更新入口的 1.9.10 兼容桥进入下载，实际安装和显示的仍是新客户端 1.0.0；新客户端后续独立遵循 SemVer。

- 全新设计的深色、浅色与系统主题，重新布局导航、海报片单、剧集详情、播放器和设置。
- 搜索、推荐、排行榜、真人短剧、漫剧与 AI 剧筛选；选集、评论、快捷键、倍速、画质和自动连播。
- 独立媒体状态机，边转边播、预取后两集、取消与缓存容量管理。
- 观看记录先存本机，网络恢复后重试；账号独立隔离，旧离线进度不会覆盖手机上的新进度。
- 账号凭据使用 Windows DPAPI 加密，渲染界面无法访问登录凭据。
- 首次启动只读导入旧版账号、历史、收藏及可迁移偏好，保留旧安装和原数据。

下载 `hongguo-1.0.0-setup.exe` 安装即可。源码和运行时构建资源公开发布，安装无需管理员权限。

当前已完成自动测试与真实片单、视频解码、切集、评论、主题、本机记录验收。短信发送与 MFA 登录仍需实际账号验证。
