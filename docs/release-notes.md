红果桌面 1.1.0：完整观看历史、播放与加载体验优化。

- 视频真正全屏：隐藏导航和选集，保持画面比例；按钮、F 和双击均可操作，Esc 只退出全屏。
- 首页先显示最近真实片单，再后台刷新；返回片单保留浏览位置和筛选，连接较慢时给出明确提示。
- 下一集提前准备和解码，切换时保留当前画面到新画面就绪，减少短暂黑屏。
- 顶部增加历史、收藏和账号快捷入口，优化手机号输入框与加载状态。
- 历史使用完整 SQLite 存储，按真实观看时间排序和日期分组，提供搜索、时间筛选和分页；不再固定只保留一百条。
- 修复 PC 观看进度的单位及遗漏独立续播记录的问题，历史和播放进度同时同步到手机。
- 覆盖安装自动关闭安装目录下的关联进程，避免旧签名服务占用文件导致安装失败。
- 剧场模式扩大到窗口内完整可用区域，T 或按钮可恢复原布局。
- 首次缓存按完整单集时长显示时间和进度，支持定位到尚在准备的位置；暂停立即保存进度。
- 增加动作、爱情、年代、传奇等真实题材分类，首页快捷筛选；探索片库可组合题材、设定和背景，并加载更多作品。

下载 `hongguo-1.1.0-setup.exe` 覆盖安装即可，保留已有账号、历史和偏好。
